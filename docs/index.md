# 地震学学习笔记

这里记录地震学相关的学习笔记，包括震源理论与地震波衰减。

## 震源理论

- **Brune 模型**：圆形裂纹震源谱、地震矩、拐角频率、应力降

## 地震波衰减

- **谱比法 Q 值反演**：品质因子 Q 的定义、双台站谱比推导、线性回归提取 Q 值

## 垂直地震剖面（VSP）

- **VSP 原理与应用**：观测几何、波场组成、波场分离（F-K 滤波）、速度建模、Q 值估计、VSP-CDP 成像

## 面波与尾波

- **波速提取与监测**：Rayleigh/Love 波频散分析、频散反演 Vs(z)、尾波 Qc 估计、尾波干涉法（CWI）速度变化监测

## 地震数据处理

- **F-K 分析与 Radon 变换**：视速度原理、扇形滤波、空间假频；线性/抛物线/双曲 Radon；稀疏 Radon（IRLS）；Capon MVDR 与 MUSIC 高分辨率波数谱

## DAS 分布式声学传感

- **基本原理与应用**：瑞利散射与 φ-OTDR、平坦频率响应、方向性响应、标距效应

## 冰川地震学

- **仪器、阵列与 DAS 应用**：冰震信号分类、宽频地震仪与检波器部署、阵列波束形成定位、矩张量反演、DAS 冰面/冰孔铺设、冰川结构成像、冰震精细定位、粘-滑监测与 CWI 速度变化
