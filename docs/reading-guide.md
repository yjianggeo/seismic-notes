## 容易混淆的量

| 量 | 定义与单位 | 不宜直接等同的量 |
|---|---|---|
| 位移 \(u\) | 质点位移，m | DAS 应变或应变率 |
| 应变 \(\varepsilon\) | 位移空间梯度的对称部分，无量纲 | 位移本征函数 |
| 应变率 \(\dot\varepsilon\) | 应变时间导数，s⁻¹ | 粒子速度 |
| 标距 \(L_g\) | 单道的空间平均长度，m | 道间距、整井孔径 |
| 沿井距离 \(\ell\) | 沿井轨迹的弧长，m | 真垂深 \(z\) |
| 沿井慢度 \(q\) | \(dt/d\ell=\mathbf p\cdot\mathbf t\)，s/m | 材料速度的倒数 |
| 相速度 \(c\) | 等相位面传播速度，m/s | 包络/波包群速度 \(U\) |
| 相干度 | 按所选定义衡量相位/谱或空间结构一致性 | 振幅、耦合刚度、信号存在的统计显著性 |
| BI / 状态指标 | 给定频带、归一化与场景下的代理量 | 通用埋深或机械传递系数 |
| 先验模型 | 外部资料或约束形成的参数范围 | 本次观测独立恢复的结构 |

## 怎样使用这些笔记

先写清测量量、坐标、符号与 sinc 定义，再比较不同文献公式。保留观测、解释和反演三层表述：波包或相关峰属于观测；波型和机制是待比较的解释；速度和耦合参数需要正演、误差模型与分辨率支持。

中文与英文文章通过页头按钮切换。学习页中的公式均应连同假设阅读；教学示意与机制合成不能替代实测验证。近期新增文献及阅读范围见 [文献学习索引](literature-notes.md)。
